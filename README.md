# Emotion Detection from Facial Expressions

## Project Overview
This project uses deep learning to detect human emotions from facial images.  
A Convolutional Neural Network (CNN) model is trained to classify facial expressions into different emotion categories.

The system can predict emotions such as:
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

The trained model can also perform **real-time emotion detection using a webcam**.

---

## Dataset
The model was trained using the FER2013 facial emotion dataset.

Dataset source:
https://www.kaggle.com/datasets/msambare/fer2013

The dataset contains around **35,000 labeled grayscale facial images (48x48 pixels)**.
